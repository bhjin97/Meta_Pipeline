# E-Commerce Hybrid Data Pipeline

> Kafka와 Spark를 기반으로 실시간 이벤트와 배치 데이터를 통합 처리하고,  
> Bronze–Silver–Gold 계층을 거쳐 분석용 데이터 마트로 제공하는 하이브리드 데이터 파이프라인입니다.
